# Changelog

## 1.0.0 — 2026-11-13

- Initial release.
- Left-sidebar entry and main panel for the DSH Web UI.
- Open from file picker, drag-and-drop, clipboard paste, and Clipboard API.
- Crop with selection overlay and dimensions.
- Rotate 90°, flip horizontally/vertically.
- Resize with optional aspect-ratio lock.
- Brightness, contrast, saturation, grayscale, sepia, invert.
- Undo/redo history (20 steps).
- Export PNG/JPEG with quality control.
- English and Chinese UI, light/dark theme tokens.
